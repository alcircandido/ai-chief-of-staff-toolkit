# Playbook: one look for pictures, decks and pages

## When to use it

Before making anything the person or their audience will look at: a chart, a slide, a picture for a post, a review page.

## What good looks like

Keep 2 or 3 finished pieces the person approved in a folder beside this file and name them here. New work is laid next to them before it is handed over.

## The steps

1. Write the one thing the picture must say, in a sentence. If it needs two sentences, it is two pictures.
2. Use the tokens below and nothing else. A color that is not in the list is a mistake, not a choice.
3. Give each color one meaning and keep it everywhere (for example: one for structure, one for a person deciding, one for an agent).
4. Set the title as a real header and keep labels large enough to read on a phone.
5. Render the piece to an image and look at the image, at full size and shrunk to phone width.
6. Run the check below.

## The tokens

Fill these once. Every agent that draws anything reads them from here.

| Token      | Value     | Used for                 |
|------------|-----------|--------------------------|
| ink        | {#000000} | text, structure          |
| accent     | {#000000} | the one thing to notice  |
| positive   | {#000000} | done, agent, go          |
| page       | {#FFFFFF} | background               |
| heading    | {font}    | titles                   |
| body       | {font}    | everything else          |

## Hard rules

- No color and no font outside the tokens.
- One picture, one idea. A slide carries one picture and few words.
- Text never touches or overlaps another element. No cut words.
- A review page shows each item once and puts at most 3 decisions in front of the person, each with a suggestion.

## The check before handing over

- Script: render to an image; test that no text box overflows, no two boxes overlap and every arrow ends on a box.
- Look at the rendered image yourself. A layout that passes the script can still read badly.
- Shrink it to phone width. If a label cannot be read, cut words before shrinking type.
